# Telegram-бот «Управление заявками на материалы»

Telegram-бот для управления заявками на стройматериалы с хранением данных в Google Sheets и автоматической ежедневной отчётностью.

## Возможности

- **Добавление заявок** — 6-шаговый диалог: наименование, количество, единица измерения, инициатор, объект, примечание
- **Подтверждение перед записью** — сводка с кнопками «Подтвердить» / «Отмена» перед сохранением
- **Ежедневный отчёт** — автоматическая отправка сводки по активным заявкам (по расписанию)
- **Ручной анализ** — администратор может запустить отчёт в любой момент
- **Роли** — разделение прав между администратором и обычным пользователем
- **Кэширование** — TTL-кэш для Google Sheets и авторизованного клиента
- **Динамические списки** — инициаторы и объекты загружаются из таблицы

## Быстрый старт

### 1. Клонировать и установить зависимости

```bash
git clone <repo-url>
cd Telegramm_bot
python -m venv .venv
.venv\Scripts\activate       # Windows
pip install -r requirements.txt
```

### 2. Настроить Google Sheets

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите API Google Sheets
3. Создайте Service Account и скачайте JSON-ключ → сохраните как `credentials.json`
4. Расшарьте таблицу на email сервисного аккаунта (из credentials.json)
5. Структура таблицы — два листа:

**Лист `Input`** (основные данные):

| Наименование | Кол-во | Ед. изм | Дата заявки | Дата выполнения | Инициатор | Статус | Объект | Примечания |
|---|---|---|---|---|---|---|---|---|

**Лист `Team`** (список инициаторов, колонка A):

| Имя |
|---|
| Иван |
| Петр |
| Анна |

### 3. Настроить переменные окружения

Создайте файл `.env`:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_CHAT_ID=ваш_chat_id
ADMIN_IDS=123456789,987654321

GOOGLE_CREDENTIALS_FILE=credentials.json
GOOGLE_SHEET_ID=ид_вашей_таблицы
GOOGLE_SHEET_NAME=Input

OVERDUE_DAYS=3
REPORT_HOUR=9
REPORT_MINUTE=0
CACHE_TTL=300
```

### 4. Запустить бота

```bash
python bot.py
```

## Команды бота

| Команда | Кто видит | Описание |
|---|---|---|
| `/start` | Все | Главное меню |
| `➕ Добавить заявку` | Все | Запуск диалога добавления заявки |
| `📊 Анализ` | Админ | Ручной запуск отчёта |
| `🔄 Обновить кэш` | Админ | Сброс кэша Google Sheets |
| `⛔ Выход` | Все | Возврат к кнопке `/start` |
| `❌ Отмена` | Все | Отмена текущего диалога (на любом шаге) |

## Диалог добавления заявки

```
Шаг 1/6 → Наименование товара/услуги
Шаг 2/6 → Количество (число)
Шаг 3/6 → Единица измерения (кнопки)
Шаг 4/6 → Инициатор (кнопки, из листа Team)
Шаг 5/6 → Объект (кнопки, из таблицы)
Шаг 6/6 → Примечание (или «-» для пропуска)
Подтверждение → ✅ Подтвердить / ❌ Отмена
```

## Статусы в отчёте

| Эмодзи | Значение |
|---|---|
| ⚪ | Новая заявка (не заказана, не просрочена) |
| 🟡 | Заказана (в примечании есть «заказ») |
| 🔴 | Просрочена (более `OVERDUE_DAYS` дней) |

```
    ├── test_core.py          # Тесты анализа данных
    ├── test_google_sheets.py # Тесты работы с таблицей
    └── test_utils.py         # Тесты утилит
```

## Переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Да | — | Токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | Да | — | ID чата для отправки отчётов |
| `GOOGLE_SHEET_ID` | Да | — | ID Google-таблицы |
| `ADMIN_IDS` | Нет | `""` | Telegram ID администраторов через запятую |
| `GOOGLE_CREDENTIALS_FILE` | Нет | `credentials.json` | Путь к файлу сервисного аккаунта |
| `GOOGLE_SHEET_NAME` | Нет | `Input` | Имя листа с данными |
| `OVERDUE_DAYS` | Нет | `3` | Дней до просрочки заявки |
| `REPORT_HOUR` | Нет | `9` | Час отправки ежедневного отчёта |
| `REPORT_MINUTE` | Нет | `0` | Минута отправки отчёта |
| `CACHE_TTL` | Нет | `300` | Время жизни кэша в секундах |
